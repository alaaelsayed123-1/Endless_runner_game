# 🎮 Endless Runner Game

A 3D endless runner game built using Unity and C#.

## 🚀 Features

* Player movement (left / right)
* Jump system
* Running animation
* Obstacle avoidance

## 🎮 Controls

* Move Left / Right → Arrow keys or A/D
* Jump → Space

## 🛠️ Built With

* Unity
* C#
